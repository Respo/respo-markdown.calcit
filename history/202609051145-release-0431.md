# Release 0.4.31

- Upgrade to Calcit and `@calcit/procs` 0.13.77.
- Align Respo Markdown with the compatible Respo 0.16.91 and Respo UI 0.7.16 releases.
- Keep incremental block parsing type-safe by using a tag sentinel when an optional block kind is absent.

# 发布 0.4.31

- 升级 Calcit 与 `@calcit/procs` 到 0.13.77。
- 对齐已兼容的 Respo 0.16.91 与 Respo UI 0.7.16 正式版本。
- 可选 block 类型缺失时改用 tag 哨兵，保持增量 block 解析的静态类型安全。
