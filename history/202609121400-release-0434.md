# Release 0.4.34

- Upgrade respo-markdown to the Calcit 0.14.11 toolchain (`@calcit/procs` 0.14.11) and align the provider chain to respo-ui 0.7.20, respo-router 0.8.14, Respo 0.16.97, and js-ffi 0.1.16.
- Replace legacy originless struct/string/list methods (`.strip-prefix`, `.trim`, `.slice`, `.split`, `.map`, `.replace`, `.join-str`, `.!replace`, `.!toISOString`) with typed functions, `&str:*`/`&list:*`/`&map:*` accessors, and declared `StringHost`/`DateHost` external-object traits.
- Introduce explicit dynamic-value adapters (`unwrap-option`, `unwrap-or`, `coalesce`, `map-indexed-dynamic`) and type the remaining component, atom, and math-parser boundaries.
- Migrate legacy `?` optional parameters to explicit arguments.
- Reviewed baseline update: `typeNotFull` 100 -> 105 for the added adapters, while `schemaDynamic` drops 101 -> 64 and `unresolved` 136 -> 94.
- Revalidated strict Caps, `--check-only` (zero warnings), MathML and incremental JS smoke tests, deprecated check, the type/weak-type/deprecated analyses, the upgrade baseline, JS code generation, and the Vite production build.
