# Respo UI 0.7.13 upgrade / 升级 Respo UI 0.7.13

## 中文

- 将 respo-markdown 的 Respo UI 依赖从 0.7.12 升级到 0.7.13。
- 保持 Calcit CLI 与 `@calcit/procs` 0.13.64、Markdown/MathML API 与增量解析语义不变。
- 通过 strict Caps、MathML smoke、incremental tests、静态 baseline、JS codegen 与 Node 24 Vite build 验证。

## English

- Upgrade the respo-markdown Respo UI dependency from 0.7.12 to 0.7.13.
- Keep Calcit CLI and `@calcit/procs` 0.13.64, Markdown/MathML APIs, and incremental parsing semantics unchanged.
- Verify with strict Caps, MathML smoke, incremental tests, the static baseline, JS codegen, and the Node 24 Vite build.
